OPEN THE WEBSITE
Extract the website ZIP and open index.html in a current browser. All fonts,
photography and graphics are local. No build step or network connection is
required. Keep the assets folder beside the HTML, CSS and JavaScript files.
The corporate PDF download is included in the website folder.

EDIT THE WEBSITE
Text and structure: index.html
Palette, type, layout and responsive rules: styles.css
Menu, approach panels and enquiry dialog: app.js
Vector monogram and particle wave: assets/monogram.svg and particle-wave.svg

EDIT THE FLYER
Open flyer.html and edit the text directly. Edit flyer.css for layout.
The standalone editable ZIP includes all required assets.
To export again, open flyer.html in Edge or Chrome and choose Print / Save
as PDF. Select A4, no margins, background graphics on, headers and footers
off, and 100% scale. Confirm the preview shows exactly two pages.
The delivered PDF was rendered using Chromium and checked with Poppler.
It is suitable for desktop printing and digital distribution. It is RGB,
without bleed or crop marks; ask a print provider for any press-specific
CMYK/PDF-X conversion before commercial production.
