are local. No build, installation, account or network connection is required.

EDITING
Content is directly editable in each HTML file.
styles.css contains the original brand and home styles.
pages.css contains the full website layouts and shared navigation styles.
app.js handles mobile menus, the fixed header, accordions, enquiry type
preselection and local enquiry preview.
assets/ includes the vector monogram, particle wave, architecture photograph,
local Montserrat/Inter fonts and font license files.

INTERACTIONS
The logo returns home. The main and footer links connect the pages.
Focus area links scroll to the relevant section below the fixed header.
Partnership links preselect the corresponding corporate enquiry category.
The enquiry form validates fields and opens a local review dialog.
No enquiry is sent or stored by the application. There is no backend or
analytics service. Browser autofill is controlled by the visitor's browser.
The corporate flyer download is included locally.
